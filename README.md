# Campus Connect

Build a modern responsive website called “SkillSwap Campus” where college students can exchange skills with each other.

Features:

- Student signup/login and profile

- Add skills they can teach and skills they want to learn

- College, department, year, skill level and availability

- Smart matching system with match percentage

- Discover students with search and filters

- Send/accept match requests

- Student-to-student chat

- Session scheduling

- Ratings and reviews

- Notifications

- Student dashboard

- Admin dashboard

Create an attractive, modern, student-friendly UI with responsive mobile and desktop design, smooth animations, cards, clean navigation and a professional color scheme. Make the website functional and easy to use.
